# cnmf_magnetic-couplers
Universal magnetic coupler design for H0 and N model railway scales, for 3D printing and injection molding.

The source files contain the Inventor files for parts, drawings and assemblies. Use these if you want to make changes to the coupler shaft to adapt to non-covered coupler boxes.
Releases contain STL files for 3D printing. STL files already contain everything for UV resin printing. Just drop the files on the table and bypass the creation of supports.
